# QR Studio — Smart QR Code Generator & Designer

QR Studio is a Python-powered web application for creating customized QR codes. It includes a visual designer, color presets, optional logo overlay, PNG/JPEG export, local history, and batch generation with ZIP download.

## Features

- Generate QR codes from URLs and text.
- Customize foreground/background colors.
- Choose error correction levels L, M, Q, and H.
- Adjust resolution and quiet-zone border.
- Optional center logo using Pillow.
- Export individual QR codes as PNG or JPEG.
- Batch-create up to 100 QR codes from `.txt` or `.csv` and download them as one ZIP.
- Local recent-code history stored in `history.json`.
- Responsive dashboard with an illustrative live preview.

> The live preview is a visual placeholder pattern, not a scannable QR code. The downloadable image is the real QR code generated by the Python backend. Scan-test exported images before using them.

## Technology

- Python 3
- Flask — web server and form handling
- `qrcode` — QR encoding and image generation
- Pillow — image conversion and optional logo overlay
- HTML, CSS, JavaScript — interface and preview

## Setup

### 1. Download or clone this project

```bash
git clone https://github.com/YOUR-USERNAME/qr-studio.git
cd qr-studio
```

Alternatively, download the ZIP from GitHub and extract it.

### 2. Create a virtual environment (recommended)

Windows:

```bash
py -m venv .venv
.venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

Open http://127.0.0.1:5000 in your browser.

## Batch input formats

### Text file

Put one QR item on each line:

```text
https://example.com
Hello from QR Studio
https://python.org
```

### CSV file

The first column is used. A header named `data`, `text`, `url`, or `content` is optional.

```csv
data
https://example.com
https://python.org
Hello from QR Studio
```

The batch tool creates up to 100 PNG files in a ZIP archive. Batch generation currently uses one shared color palette and error-correction level for the entire batch.

## Important implementation notes

- The app limits batch inputs to 100 entries to avoid excessive resource use.
- Logo overlays can make QR codes harder to scan. High error correction helps but does not guarantee scanability. Test every exported image.
- QR content may contain sensitive data. Avoid encoding private information in public-facing QR codes.
- History is stored locally in `history.json` and retains up to 200 recent entries. Avoid entering secrets if you do not want them saved in history.
- This development configuration uses Flask's local server with debug mode enabled. **Do not deploy it publicly as-is.** Change the secret key, disable debug mode, and use a production WSGI server before hosting.
